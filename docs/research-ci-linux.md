## Startup boundary

- Tauri driver 2.1.0 supplies `TAURI_WEBVIEW_AUTOMATION=true` to its native driver. Tauri's runtime reads that environment variable and enables automation on its first web context; this path is not conditional on a debug build. Wry registers that context's automation callback. Sources: [driver](https://github.com/tauri-apps/tauri/blob/tauri-driver-v2.1.0/crates/tauri-driver/src/webdriver.rs), [runtime](https://github.com/tauri-apps/tauri/blob/tauri-runtime-wry-v2.12.1/crates/tauri-runtime-wry/src/lib.rs), [Wry](https://github.com/tauri-apps/wry/blob/wry-v0.57.0/src/webkitgtk/web_context.rs). The installed locked crate sources were inspected directly as well.
- WebKitGTK 2.52.6 launches the application with `WEBKIT_INSPECTOR_SERVER` pointing at a free loopback port. Its session host retries connection-refused errors without a fixed attempt limit; if the app disappears, that path can return without completing the pending callback. Thus an unanswered `/session` can arise before automation negotiation finishes. This is a source-derived possible mechanism, not the proven explanation of this run. Source: [version-matched SessionHostGlib.cpp](https://github.com/WebKit/WebKit/blob/webkitgtk-2.52.6/Source/WebDriver/glib/SessionHostGlib.cpp#L126-L201).
- Tauri's official CI recipe installs `webkit2gtk-driver` and Xvfb and runs the application test under Xvfb. It does not require disabling WebKit sandboxing. The repository already follows that basic pattern. Source: [official WebDriver CI](https://v2.tauri.app/develop/tests/webdriver/ci/), also retrieved through Context7's `/tauri-apps/tauri-docs` package.

Next diagnostic evidence should identify the application process's state, whether its loopback inspector port opens, and whether its automation environment reaches it. Preserve the exact hosted release binary as a short-lived CI artifact for a controlled Ubuntu reproduction. Change one startup variable at a time. Do not infer a need for AppArmor, TLS, CSP or WebKit sandbox bypasses from the accessibility warning.
